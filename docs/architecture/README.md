# Architecture

This directory contains the architecture baseline for TMB AI OS.

## Contents

- `adr/` records accepted architecture decisions.
- Future RFC documents describe proposals before acceptance.
- Architecture documents must remain synchronized with implementation.

## Principles

- Architecture changes require a documented decision.
- Public APIs preserve backward compatibility whenever practical.
- Developer tooling remains separate from application runtime code.
- The `main` branch must remain deployable and validated.
